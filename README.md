# FSG Standings

Public live standings page for Formula Student Germany, published via GitHub Pages.

`index.html` is generated by `build_standings.py` in the PythonScripts folder — it reads
CompScoringV9.xlsx and recomputes each discipline's points. The file is fully self-contained
(inline CSS/JS, no external requests), so it works on any static host.

To update:

    venv/bin/python build_standings.py --out ~/fsg-standings/index.html
    cd ~/fsg-standings && git commit -am "update standings" && git push
